# Courses

A portfolio of university coursework, project assignments, and exam materials across multiple modules, capturing practical skill development in machine learning, software testing, economics, and related academic subjects.

## Repository structure

Top-level folders in this repository:

- `5EL272`
- `ET1550 Project 1`
- `ET1550 Project 2`
- `ET1550 Project 3`
- `HIG750`
- `PA2577`
- `PA2578`
- `PA2579`

## What is included

### What this repo contains

- Course folders for 5EL272, ET1550, HIG750, PA2577, PA2578, and PA2579.
- Project-level work for ET1550 with Dockerized neural network regression, classification, and unsupervised learning examples.
- Software testing coursework in PA2578 and PA2579, including assignment solutions, unit testing submissions, mutation testing artifacts, and reflections.
- Academic writing and exam resources for Swedish economic history, quizzes, and course reflections.

### Highlights

- ET1550 Project 1 uses a neural network regression notebook with a Dockerfile and requirements for reproducible experiments.
- ET1550 Project 2 focuses on neural network classification and includes environment configuration for reproducible execution.
- ET1550 Project 3 explores unsupervised learning with development indicator data and reproducible container tooling.
- PA2579 contains in-depth testing materials with assignment submissions, Java mutation testing artifacts, and final project deliverables.
